Projects

Featured — Senior Project In development

AI-Enhanced EDR/XDR

CS497 Computer Science Project I

An AI-driven endpoint detection & response / extended detection & response platform for cloud infrastructure (built around SIAM AI Cloud). It ingests endpoint logs and telemetry with Wazuh, streams them in real time through Apache Kafka, and runs GPU-accelerated AI analysis on NVIDIA Morpheus — anomaly detection and fingerprinting to catch threats that rule-based tools miss, including zero-day attacks.

Detections trigger automated responses (block IP, isolate host) and surface on a real-time SOC dashboard, reducing analyst workload while supporting big-data-scale security monitoring.

My role (in progress): Building the detection pipeline end to end — the detection stack running in Docker with a live agent, configured to archive every event so the AI sees what signature rules miss. I built the streaming layer feeding a consumer that turns live login data into features, runs anomaly detection, and writes AI findings back to the index tagged separately from rule alerts. A custom dashboard shows both sources side by side, making the detection gap visible. Validated against controlled attacks with recorded ground truth — the model catches slow, paced attacks the rule engine never flags.

Network Penetration Testing & Security Assessment

CS471 Ethical Hacking & Penetration Testing

A full-scope penetration test against four lab machines, delivered as a 66-page professional assessment report. The engagement followed a two-phase methodology — Nessus vulnerability assessment to enumerate weaknesses, then hands-on exploitation to validate them — with every finding ranked by severity and paired with proof-of-concept evidence and prioritized remediation guidance (immediate, short-term, and long-term).

My role: I authored and formatted the entire report end to end — executive summary, methodology, all findings, and remediation — and personally owned Target 1 (Windows Server 2008 SP1), reconnaissance through exploitation. The Nessus scan surfaced 57 findings (4 critical); I exploited the critical SMB vulnerability MS09-050 (CVE-2009-3103) with Metasploit to gain a NT AUTHORITY\SYSTEM shell and capture the proof flag.

Smart Air Purifier with PM2.5 Monitoring

CS423 Internet of Things & Applications

An ESP32-based smart-home device that continuously measures airborne particulates (PM1.0 / PM2.5 / PM10) with a laser sensor and automatically switches a fan on when air quality drops or a person is detected. Built on a three-layer IoT architecture with live readings on an on-device OLED and streamed to the Blynk cloud for remote monitoring.

My role: solo build — hardware wiring, the Arduino (C++) firmware, and the full project report.
