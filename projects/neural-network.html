Neural Network from Scratch

A feedforward neural network in C++, with every layer and gradient written by hand.

Code on GitHub

A feedforward neural network written from first principles in C++ — no machine-learning or maths libraries, no shortcuts. Every neuron, layer, and gradient is hand-written, so the maths behind training is implemented rather than imported. I built it to genuinely understand what happens inside a model instead of only calling a framework.

Built in stages: a single neuron, then layers, a full forward pass, weight initialisation, the loss function, backpropagation, gradient descent, and a training loop that learns XOR.

Built with

C++Neural networksBackpropagationGradient descent

How it's set up

  • A 2-4-1 network: two inputs, a hidden layer of four sigmoid neurons, and one sigmoid output.
  • Weights and biases start random, between −1 and 1.
  • Mean squared error as the loss, a learning rate of 0.5, and 3,000 passes over the four XOR cases, updating the weights after every example.
  • Each layer can use sigmoid or ReLU, and backpropagation uses the matching derivative.

Why XOR

XOR is the smallest problem a single neuron can't solve: no straight line separates the ones from the zeros. The hidden layer has to learn something first, so if any part of backpropagation is wrong, XOR is where it shows.
