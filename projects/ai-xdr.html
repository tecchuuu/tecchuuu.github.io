AI-Enhanced XDR

Behavioural AI on top of Wazuh's rules, built to catch the attacks that stay under rule thresholds.

Code on GitHub

What it does

Signature rules catch attacks that cross a threshold. This project catches the ones that stay under it. Every event from the monitored host streams through Apache Kafka to anomaly-detection models, including NVIDIA Morpheus's DFP on an H100 GPU, and lands next to Wazuh's alerts in a SOC console I built. The console shows why each detection fired, has a local LLM to explain it, supports analyst triage, and blocks an IP only after a human confirms it.

What it found

Tested with live attacks, a public labelled dataset and my own lab data, the AI caught brute force spread across many addresses, which Wazuh's standard alert level missed. Only NVIDIA's model reliably caught password guessing slowed to one attempt every few minutes.

Rules still win on single crafted requests, like one SQL injection. So the answer is both, not one instead of the other.

How it's built

  • Wazuh collects SSH and web logs and archives every event, not just the ones a rule matches, so the models also learn what normal looks like.
  • Filebeat streams that archive into Kafka, and each detector reads the full stream on its own.
  • Three swappable models score one-minute windows: Isolation Forest, a PyTorch autoencoder, and Morpheus DFP running as a Morpheus pipeline on the H100.
  • The console (FastAPI and React) shows Wazuh alerts and AI detections side by side, explains each detection, and records every triage decision and block.
  • A local LLM, Gemma 3 on Ollama, writes the explanations, so no log data leaves the machine.
  • Everything runs as containers started by one command.

My role

I built the detection pipeline, the three models and their evaluation, the SOC console, and the deployment on SIAM AI Cloud's H100.

Where it started
